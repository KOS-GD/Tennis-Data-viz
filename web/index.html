Qui est le meilleur joueur de tennis de l'histoire ?

Ça dépend de ce que vous comptez. Réglez l'importance de chaque critère et regardez le classement changer.

Données fictives : lancez python -m scripts.build_data pour charger les vraies.

Classement réglable

Chaque critère est converti en rang (0 = dernier, 1 = premier du groupe) avant d'être pondéré. Un critère non disponible pour un joueur ne le pénalise pas : il est retiré de son calcul.
